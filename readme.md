# Basic AI Chatbot

## Project Description
This project is a basic chatbot that can remember responses from previous conversations. The goal is to create a simple program that learns new responses through user input.

## Features
- Responds to user questions
- Stores previously learned responses
- Allows users to teach the chatbot new answers
- Uses basic programming concepts and data storage

## Installation
1. Clone this repository.
2. Open the project in your preferred code editor.
3. Run the chatbot program.

## Usage
1. Start the program.
2. Type a question for the chatbot.
3. If the chatbot does not know the answer, provide a response.
4. The chatbot can use that response in future conversations.
